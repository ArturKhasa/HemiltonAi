# Корневые сертификаты Минцифры

По ним работает мессенджер MAX: и Bot API (`platform-api2.max.ru`), и хранилище
медиа, откуда мы забираем присланные клиентом фото и голосовые. В общемировых
хранилищах доверенных корней этого центра нет, поэтому без них любой запрос к
MAX падает с

```
[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed: unable to get local issuer certificate
```

— то есть бот молча перестаёт отвечать.

| Файл | Что это | Действует до |
|------|---------|--------------|
| `russian_trusted_root_ca.pem` | Russian Trusted Root CA | 27.02.2032 |
| `russian_trusted_sub_ca.pem` | Russian Trusted Sub CA (выпущен корнем выше) | 06.03.2027 |

Источник — портал Госуслуг: <https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer>
и `.../russian_trusted_sub_ca.cer`. Файлы уже в PEM, публичные, секретов не
содержат — потому и лежат в репозитории, несмотря на общий запрет `*.pem` в
`.gitignore`.

## Как они используются

- **В образе** (`Dockerfile`): кладутся в системное хранилище
  (`update-ca-certificates` — для curl и прочих утилит) и дописываются в связку
  `certifi`, по которой проверяют сертификаты httpx и клиенты моделей;
  системное хранилище они не читают.
- **В коде** (`app/ssl_trust.py`): SSL-контекст собирается как «обычные корни +
  всё, что лежит в этом каталоге», и используется в запросах к MAX и при
  скачивании медиа. Благодаря этому всё работает и вне докера — например, при
  локальном запуске `uvicorn`.

Каталог задаётся настройкой `RU_TRUSTED_CA_DIR` (по умолчанию `certs`).

## Когда обновлять

Когда истечёт Sub CA (март 2027) или Минцифры выпустит новый корень: скачать
свежие файлы по ссылкам выше, положить сюда с расширением `.pem` и пересобрать
образ. Проверить, что всё в порядке, можно так:

```bash
docker compose run --rm app python -c "import asyncio; from app.max.client import get_me; asyncio.run(get_me('нерабочий-токен'))"
```

Ответ `MAX API error 401/verify.token` означает, что TLS в порядке (до проверки
токена дело дошло). Ошибка `CERTIFICATE_VERIFY_FAILED` — сертификаты не
подхватились.
